# Blog do Victor Soares

Site estático feito com [Astro](https://astro.build), publicado no GitHub Pages em https://victorsoad.github.io

## Como publicar um post

1. Crie um arquivo em `src/content/posts/` com o nome `AAAA-MM-DD-slug.md` (o 05-blog.md do fluxo editorial já sai nesse formato).
2. Faça o commit na branch `main`. O GitHub Actions monta e publica o site em 1–2 minutos.

Para deixar um post escondido, use `rascunho: true` no cabeçalho.

## Categorias

`ia` · `desenvolvimento` · `fintech` · `carreira` · `regulatorio`

## Rodar no computador (opcional)

```
npm install
npm run dev
```
